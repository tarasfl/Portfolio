# Portfolio Website

Academic research portfolio built with Astro.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

## 📁 Project Structure

```
src/
  ├── components/      # Reusable components
  ├── layouts/         # Layout templates
  ├── pages/           # Routes
  ├── styles/          # Global styles
  └── content/         # Markdown content
```

## 📄 Sections

- **Home** - Landing page with introduction
- **About** - Background, academic focus, and links
- **Research & Projects** - Technical projects and contributions
- **Technical Notes** - Articles and derivations
- **Experience** - Internships, hackathons, and leadership
- **CV** - Academic curriculum vitae
